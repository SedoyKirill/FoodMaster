# Конфигурация

Единственный источник настроек — файл `.env` в корне репозитория. Он не попадает
в git; шаблон — `.env.example`, и в нём обязана быть перечислена каждая
переменная, которую читает код.

> English version: [configuration.md](configuration.md)

Файл `.env` читают двое: **Docker Compose** (для подстановки в
`docker-compose.yml`) и **приложение** (через `app/core/config.py`,
pydantic-settings). Поэтому в нём есть ключи, которые приложение игнорирует
(`POSTGRES_PASSWORD`, `WEB_BIND_IP`, `DB_PORT`) — за это отвечает
`extra="ignore"` в настройках модели.

Compose переопределяет ровно два значения для контейнеров — `DATABASE_URL` и
`OLLAMA_URL`, — потому что только они отличаются между «внутри Docker» и «на
хосте». В `.env` лежит вариант для Docker, а `scripts/dev.ps1` подставляет
хостовый через переменные окружения процесса (pydantic-settings ставит их выше
файла `.env`). Отдельного `.env.dev` нет намеренно: он разошёлся бы за неделю.

## Приложение

| Переменная | Тип | По умолчанию | Назначение |
|---|---|---|---|
| `APP_ENV` | `prod\|dev\|test` | `prod` | Режим работы |
| `APP_TIMEZONE` | строка | `Europe/Moscow` | Часовой пояс семьи. Определяет время ночных задач и то, «какое сегодня число» (см. `app/core/clock.py`). Контейнеры живут в UTC, поэтому без него парсер в 03:00 записал бы цены вчерашним днём |
| `LOG_FORMAT` | `json\|console` | `json` | `console` удобнее при локальной разработке |
| `LOG_LEVEL` | строка | `INFO` | |

## База данных

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `POSTGRES_USER` / `POSTGRES_PASSWORD` / `POSTGRES_DB` | `ration` | Учётные данные сервиса `db`. Только для Compose |
| `DB_PORT` | `5432` | Порт на хосте (только `127.0.0.1`). Нужен для `dev.ps1`, pytest и клиента БД |
| `DATABASE_URL` | `postgresql+asyncpg://ration:ration@db:5432/ration` | **Обязан начинаться с `postgresql+asyncpg://`** — проверяется валидатором, иначе ошибка всплыла бы глубоко внутри SQLAlchemy |

## Веб

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `WEB_BIND_IP` | `127.0.0.1` | `0.0.0.0` открывает доступ из домашней сети. Заменяет `WEB_EXPOSE` из ТЗ — см. [setup.ru.md](setup.ru.md) |
| `WEB_PORT` | `8000` | Порт на хосте |

## LLM

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `LLM_PROVIDER` | `none` | `none` — полностью кнопочный режим, всё работает без LLM; `ollama`; `claude` |
| `OLLAMA_URL` | `http://ollama:11434` | |
| `OLLAMA_MODEL` | `qwen3:8b` | Смена значения и `docker compose up -d` автоматически скачают новую модель |
| `OLLAMA_KEEP_ALIVE` | `10m` | Сколько модель остаётся в видеопамяти между запросами. Холодная загрузка стоит 5–10 с из бюджета в 15 с у M5 |
| `OLLAMA_TIMEOUT_S` | `120` | |
| `ANTHROPIC_API_KEY` | пусто | Обязателен при `LLM_PROVIDER=claude` — проверяется при старте, а не при первой генерации плана в 22:00 |

## Эмбеддинги (M2)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `EMBEDDING_MODEL` | `intfloat/multilingual-e5-small` | |
| `EMBEDDING_DIM` | `384` | Сверяется при старте с `VECTOR(384)` в схеме; расхождение — ошибка запуска, потому что менять размерность можно только миграцией |

## Магазины (M3)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `STORES` | `5ka,lenta` | Список через запятую. Обратите внимание: поле помечено `NoDecode`, иначе pydantic-settings попытался бы разобрать значение как JSON и упал бы при старте |
| `FIVEKA_STORE_ID`, `LENTA_STORE_ID` | пусто | Идентификаторы ближайших магазинов; заполняются в M3 |
| `STORE_REQUEST_DELAY_S` | `1.0` | Не чаще одного запроса в секунду |

## Планировщик и бэкапы

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PARSE_CRON_HOUR` / `PARSE_CRON_MINUTE` | `3` / `0` | Ночной сбор каталогов (M3) |
| `BACKUP_CRON_HOUR` / `BACKUP_CRON_MINUTE` | `4` / `30` | Специально после парсинга, чтобы дамп содержал ночные цены |
| `BACKUP_DIR` | пусто | Второе место хранения дампов, **путь внутри контейнера**. См. [backup-restore.ru.md](backup-restore.ru.md) |
| `BACKUP_KEEP` | `14` | Сколько дампов хранить в каждом месте |
| `NAS_HOST`, `NAS_SHARE`, `NAS_USER`, `NAS_PASSWORD` | пусто | Только для `docker-compose.nas.yml` |
