# Промт: разметка кухни и типа блюда (offline-этап, по подписке)

Ты — классификатор рецептов. Тебе даётся файл-пачка
`F:\Cloud\Eda\data\recipes\cuisines\batch-NNN.md` со строками:

```
id | название рецепта | книга-источник | ингредиенты (первые)
```

Для КАЖДОЙ строки определи два атрибута и запиши результат в
`F:\Cloud\Eda\data\recipes\cuisines\extracted\batch-NNN.json`:

```json
{
  "batch": "batch-NNN",
  "items": [
    {"id": 30014, "cuisine": "japanese", "dish": "drink"},
    {"id": 30015, "cuisine": null, "dish": "soup"}
  ]
}
```

## cuisine — СТРОГО один из кодов или null

| код | когда ставить |
|---|---|
| russian | русская классика: щи, борщ*, каши, блины, пироги, соленья |
| east_european | украинская, белорусская, польская, венгерская |
| italian | паста, пицца, ризотто, брускетта, панна-котта |
| french | крем-брюле, киш, рататуй, круассаны, соусы франц. школы |
| georgian | хачапури, харчо, сациви, лобио |
| mediterranean | греческая, испанская, турецкая приморская, хумус-салаты |
| middle_eastern | ближневосточная: тахини, фалафель, шаурма, плов* |
| asian | китайская, тайская, вьетнамская, корейская |
| japanese | суши, темпура, мисо, даси, соба |
| indian | карри, масала, дал, панир |
| mexican | тако, буррито, сальса, гуакамоле |
| american | бургеры, брауни, чизкейк, барбекю, панкейки амер. книг |

- Книга-источник — сильная подсказка: рецепт из японской книги почти всегда
  japanese, из азиатской — asian (но темпура и там japanese).
- null — когда кухня не очевидна (универсальная выпечка, «просто салат»,
  смузи, детское питание, заготовки). НЕ угадывай: сомневаешься — null.
- *борщ → russian или east_european по контексту книги; плов → middle_eastern
  или asian по контексту.

## dish — СТРОГО один из кодов или null

soup (супы, бульоны, крем-супы), salad (салаты), appetizer (закуски),
sandwich (бутерброды, сэндвичи, брускетты), steak (стейки, мясо/рыба куском
на сковороде/гриле), main_course (прочие горячие блюда из мяса/рыбы/птицы),
stew (рагу, жаркое, тушёные блюда), cutlets (котлеты, тефтели, биточки,
фрикадельки), casserole (запеканки), porridge (каши), pasta (паста, лапша,
макароны), pizza (пицца), dumplings (пельмени, вареники, манты, гёдза),
pancakes (блины, оладьи, сырники, панкейки), bread (хлеб, лепёшки, багеты,
булки несладкие), pie (пироги, пирожки, киши, тарты), cake (торты, кексы,
пирожные, чизкейки), cookies (печенье, пряники, бискотти), dessert (прочие
десерты: кремы, муссы, мороженое, конфеты), drink (напитки), sauce (соусы,
заправки, маринады, пасты-приправы), preserves (заготовки: варенье, соленья,
консервация, ферментация), side (гарниры).

- Ровно ОДИН код, самый специфичный: борщ → soup (не main_course);
  тирамису → dessert; сырники → pancakes; лазанья → casserole или pasta —
  выбери pasta.
- null — только если ничего не подходит совсем.

## ЗАПРЕЩЕНО

- Скрипты, Bash, PowerShell, регулярки — ТОЛЬКО инструменты Read и Write.
- Пропускать строки: в items должна быть запись на КАЖДЫЙ id из пачки.
- Коды вне списков выше. Валидатор отбрасывает файл целиком за один
  неизвестный код.
- Писать результат, не прочитав пачку целиком.

## Порядок работы

1. Read файл пачки целиком.
2. Классифицируй строку за строкой (спокойно, без спешки).
3. Write один JSON-файл результата (UTF-8 без BOM).
4. Если пачек несколько — обработай по очереди, результат сразу после каждой.
5. В финале — только короткая статистика (сколько строк, сколько null).
