## Зафиксированные решения

- магазин: «Гипер Лента» №155, Иваново, ул. Карла Маркса, 3;
- каталог: продукты, готовая еда, вода/напитки и алкоголь;
- цены: обычная, по Карте №1, акция и, после авторизации, персональная;
- обновление: один раз ночью;
- LLM и векторная БД не входят в runtime; LLM разрешён только на этапе
  offline-импорта книг (TZ-M2R);
- всё серверное окружение запускается в Docker;
- сначала локальный web-интерфейс, затем Telegram-бот;
- пользователь вручную ведёт содержимое холодильника;
- планируются завтрак, обед и ужин;
- учитываются техника, ограничения, потребности каждого едока, бюджет и сроки
  хранения отдельных партий продуктов.
